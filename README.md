# סוכן הסל השבועי

בכל יום ראשון בבוקר הסוכן מוריד את קבצי המחירים שהרשתות מחויבות לפרסם לפי חוק,
בודק כמה עולה הסל שלך (`basket.csv`) בכל סניף בירושלים ובמבשרת ציון,
ומעדכן עמוד אינטרנט עם הדירוג.

## מה בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `basket.csv` | רשימת הקניות הקבועה, עם ברקודים. כאן משנים כמויות ומוסיפים פריטים. |
| `config.json` | ערים, רשתות, וסף "מבצע טוב" על מותג אחר (25% כברירת מחדל). |
| `compare.py` | הסוכן עצמו. |
| `page_template.html` | עיצוב העמוד. |
| `docs/` | העמוד המעודכן (`index.html`) והיסטוריית מחירים. |
| `.github/workflows/weekly.yml` | התזמון השבועי. |
| `run_weekly.bat` | הרצה מהמחשב שלך, אם צריך. |

## הקמה (פעם אחת, כ-15 דקות)

1. פותחים חשבון ב-[github.com](https://github.com) אם אין.
2. יוצרים מאגר חדש (New repository), למשל `sal-agent`. מגדירים **Public** (עמוד Pages בחינם עובד רק במאגר ציבורי; יש בו רק את רשימת הקניות ומחירים).
3. מעלים את כל הקבצים מהתיקייה (Add file ← Upload files). שימו לב שגם התיקייה `.github` עולה.
4. **Settings ← Pages**: תחת Source בוחרים `Deploy from a branch`, ענף `main`, תיקייה `/docs`.
   כתובת העמוד תופיע שם (משהו כמו `https://<שם-משתמש>.github.io/sal-agent/`).
5. **Actions ← סל שבועי ← Run workflow** כדי להריץ בפעם הראשונה בלי לחכות ליום ראשון.

## אם ההרצה ב-GitHub נכשלת

חלק מאתרי הרשתות חוסמים גישה משרתים מחוץ לישראל. אם ביומן של Actions מופיע
"לא נמצאו סניפים" או שרשתות מסוימות נכשלות, מריצים מהמחשב בבית:

1. מתקינים [Python](https://www.python.org/downloads/) (לסמן "Add to PATH") ו-[Git](https://git-scm.com/download/win).
2. בתיקייה: `pip install -r requirements.txt` ואז `python -m playwright install chromium`.
3. מתזמנים את `run_weekly.bat` ב-Task Scheduler של Windows ליום ראשון בבוקר.

## עדכון הסל

עורכים את `basket.csv`. עמודת `frequency` היא `weekly` (נכנס לסכום) או `biweekly` (מוצג, לא נכנס לסכום).
הברקוד הוא המפתח להתאמה. מוצר עם קוד קצר (ירקות, מוצרים במשקל) מותאם לפי שם, ולכן מסומן "לפי שם" בעמוד.
